# CHANGE-REQUEST-014 · 放逐平票先 PK 发言再重投

**日期**：2026-11-23
**提出者**：用户（试玩反馈）
**状态**：Accepted（已实现）

## 变更

首轮放逐投票平票时，并列者先各进行一次 PK 发言（自证不是狼），然后进入重投；
重投仍平票则当日无人出局、直接入夜。规则登记为 **RUL-16**。

## 影响

- 新增 `DAY_PK_SPEECH` 相位；只有并列者能发言；
- 首轮平票 → PK 发言 → 重投；
- 投影 `pending='speak'`、界面/状态条/复盘标签同步；
- 脚本 AI 在 PK 阶段自证；玩家可亲自发言。
