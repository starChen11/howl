# 变更请求 010 · 把「生产回路」从 AC-9 / AC-12 移到 RFC-012（C-103 / C-107）

> 提出日期：2026-11-19
> 提出人：RFC-011 第四轮评审（C-103 连续四轮未关）
> 评估基线：`RFCs/RFC-011` §2.3 / §5 AC-9 · AC-12、`RFCS.md` 依赖表、`RFCs/RFC-012`
> 决策状态：**已裁决并落地**（用户选 A）

---

## 0. 用牌桌的话说

RFC-011 要做的是「玩家和牌桌之间的接线」：玩家说的话怎么送进引擎、AI 说的话怎么显示出来。

**线已经接好了，但还没有人按开关。**

具体说：

- 「等玩家说话」的那根线（输入通道）已经能挂起、能被兑现；
- 「把 AI 的话推出去」的那根线（输出通道）也已经能推；
- 但**真正启动整局循环的那个开关**——「轮到 AI 了，让它说话；轮到你了，等你 60 秒」——属于下一份（界面与整局流程）。

评审要求这一份就把开关装上，否则通道就是「只被测试调用」的摆设。**这个要求本身是对的**，但它会让 RFC-011 和 RFC-012 的边界推倒重来。

## 1. 冲突在哪

| 位置 | 说的是什么 |
|---|---|
| RFC-011 §2.3 | 通道**住在服务端**；`HttpInputChannel` 由「`POST /actions` 的到达来兑现」 |
| RFC-011 §5 AC-9 | 「输入与输出都经过 `InputChannel` / `OutputChannel` 接口」 |
| RFC-011 §5 AC-12 | 「新增一个通道实现不需要修改 `src/engine/` 与 `src/shared/` 之外的任何文件」 |
| 实现现状 | 通道、编排队列、兑现逻辑都在；**但没有任何生产入口启动整局循环**（`runGame` 只在测试里被调用） |

评审的立场：AC-9 / AC-12 要的是「生产路径真的走通道」，现在只有测试在走。我的立场不是反驳——而是：**启动整局循环需要界面配合**（谁发起、什么时候开始、玩家在等的时候页面显示什么），那是 RFC-012。

## 2. 候选做法

### 方案 A（推荐）· 把「生产回路」迁到 RFC-012，RFC-011 保持「接线 + 兑现」

- RFC-011 的 AC-9 / AC-12 改写成「通道接口存在、`POST /actions` 能兑现挂起的输入、草稿可同步、被拒绝的发言不通知编排层」——这些**已经做到并通过测试**。
- 新增一条 AC：「整局循环由 RFC-012 的入口启动」。
- `RFCS.md` 依赖表补一条：**RFC-012 依赖 RFC-011**。

**代价**：RFC-011 少一条「生产回路」的保证；**收益**：两份 RFC 的边界与「先接线、后装开关」的施工顺序一致，不会为了满足一条 AC 把界面逻辑提前塞进服务端。

### 方案 B · 在 RFC-011 里加一个最小的启动入口

- 新增 `POST /api/games/:id/turn`，跑一步编排（AI 用 RFC-006 的 `decide()`，玩家用通道）。
- **代价**：这一份要引入「AI 决策 → 动作」的完整链路（RFC-006 的客户端 + 提示 + 降级），等于把 RFC-012 的核心提前，且与「界面那一份」严重重叠。
- **风险**：RFC-010 刚因为「接线没接上」被打了十一轮，这里再塞一次同样的东西，大概率重复。

### 方案 C · 维持现状，接受 RFC-011 不通过

- **代价**：RFC-011 永远停在 `Changes requested`，而它已经交付了可用的通道与兑现逻辑；后续 RFC 也要被迫带着这条未决项推进。

## 3. 权威检查

| 产物 | 是否要求「RFC-011 内启动整局循环」 | 结论 |
|---|---|---|
| `PRD`/`FEATURES` F21–F23 | 只要求「玩家能看到自己的身份、能发言、输入输出走通道」 | 不要求 |
| `RULES.md` ARCH-9 | 「服务端持有全部对局状态」 | 不要求由哪一份 RFC 启动循环 |
| `RFC-012` | 交付物含整局流程与界面 | 归它 |

按权威顺序，没有更高的产物要求「RFC-011 必须启动整局循环」。

## 4. 落地清单（选 A 时）

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 选了 A 之后 RFC-012 迟迟不做 | 通道长期只被测试调用 | 依赖表已把方向写死，RFC-012 是下一份 |
| 生产回路在 RFC-012 里被低估 | 又一轮「接线没接上」 | RFC-012 的 AC 里必须有一条「整局能从一个入口跑完」 |
